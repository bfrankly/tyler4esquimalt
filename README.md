# Tyler 4 Esquimalt

Campaign website for Tyler Russell, candidate for Esquimalt Township Council, 2026.
Served by GitHub Pages at https://tyler4esquimalt.ca

- `index.html` — the live site, a single self-contained page (script and photo inlined).
- `app.js` — page template, renderer and the owner-only content editor.
- `content.json` — the site's content as data.
- `build.js` — regenerates `index.html` from `app.js` + `content.json` (`node build.js`).
- `CNAME` — custom domain for GitHub Pages.

Day-to-day edits happen in the editor on the claude.ai artifact. To update this live site,
download `index.html` from the editor ("Download site file") and upload it here, replacing the old one.
